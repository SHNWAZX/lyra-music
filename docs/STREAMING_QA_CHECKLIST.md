# Streaming QA Checklist

Use this checklist when changing Lyra Music streaming behavior.

## Playback

- Start playback from search results.
- Start playback from a saved playlist.
- Skip tracks quickly and confirm the queue stays correct.
- Test a weak network connection and recovery after reconnecting.

## Account and data

- Confirm cached data refreshes without duplicating items.
- Verify logged-out states show clear actions.
- Check that failed requests do not leave stale loading indicators.
