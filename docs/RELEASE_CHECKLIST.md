# Release Checklist

Use this before publishing Lyra Music updates.

## Verify

- App starts from a clean install.
- Search and playback work on a stable network.
- Offline or weak network states are clear.
- App version and release notes match.

## Package

- Build the release artifact.
- Smoke test the artifact instead of only the debug build.
- Keep a short rollback note for the previous working version.
